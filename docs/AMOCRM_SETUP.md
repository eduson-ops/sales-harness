# 💼 Подключение AmoCRM к Sales Harness за 3 шага

> Чтобы ассистент видел воронку продаж, защищал лиды от зависания и автоматически менял статусы сделок.

---

### Шаг 1. Создать интеграцию в AmoCRM
1. Зайди в свой аккаунт AmoCRM под администратором.
2. В левом меню перейди: **Настройки** (шестеренка) ➔ **АмоМаркет / Интеграции**.
3. В правом верхнем углу нажми на три точки ➔ **Создать интеграцию**.
4. Заполни базовые поля:
   - Название: `Sales Harness AI`
   - Описание: `Автономный ассистент РОПа`
   - Предоставь права: **Сделки**, **Контакты**, **Задачи**.
5. Сохрани интеграцию.

---

### Шаг 2. Получить долгосрочный токен (Long-Lived Token)
1. В созданной интеграции перейди во вкладку **Ключи и доступы**.
2. В блоке **Долгосрочный токен** нажми **Сгенерировать**.
3. Скопируй полученный длинный токен.

---

### Шаг 3. Вставить в Sales Harness
При запуске `npm run setup` система спросит:
1. `Поддомен AmoCRM`: это имя перед `.amocrm.ru` (например, если адрес `mycompany.amocrm.ru`, вводим `mycompany`).
2. `Долгосрочный токен`: вставляем скопированный ключ.
3. `ID воронки`: перейди в раздел Сделки, в адресной строке будет цифра после `leads/pipeline/` (например `8912345`).

**Готово!** Теперь ассистент каждые 30 секунд проверяет воронку:
- Пингует сейла, если сделка висит без действия сверх лимита;
- Синхронизирует статусы проведенных встреч;
- Подсвечивает выручку дня в утреннем брифе.

# Neuroslang Cleaner — очистка текста от нейрослога

## Что такое нейрослог

Нейрослог — устойчивые формулировки, синтаксические конструкции, лексические привычки и дискурсивные приёмы, характерные для текстов, сгенерированных языковыми моделями (ChatGPT, Codex, YandexGPT и др.). Нейрослог узнаётся «на слух»: текст формально грамотен, но звучит одинаково независимо от темы, автора и аудитории.

---

## Входы

- Русскоязычный текст любого жанра и объёма.
- (Опционально) контекст: для кого текст, в каком формате будет опубликован.

## Выходы

- Переписанный текст без нейрослога.
- Краткий лог: какие паттерны были найдены и что с ними сделано (формат: `[паттерн] → [решение]`).

## Рабочий процесс

### Шаг 0. Загрузи таксономию

Перед началом работы **обязательно** открой и прочитай [`references/neuroslang-taxonomy.md`](references/neuroslang-taxonomy.md). Там — полный каталог паттернов с примерами «До → После». Без этого файла не работай.

### Шаг 1. Диагностика

Прочитай текст целиком. Определи:

1. **Плотность нейрослога** — примерная доля предложений с хотя бы одним паттерном.
   - Лёгкий (< 20 %) — точечные замены, структура сохраняется.
   - Средний (20–50 %) — замены + перестройка абзацев.
   - Тяжёлый (> 50 %) — переписывание с нуля по смыслу оригинала.
2. **Доминирующие паттерны** — какие категории из таксономии преобладают.
3. **Контекст текста** — жанр, аудитория, регистр. Это определяет, чем заменять.

### Шаг 2. Переписывание

Применяй правила из таксономии по приоритету:

1. **Семантические пустышки** → удаляй без замены (если смысл не теряется) или заменяй конкретикой.
2. **Синтаксические клише** → перестраивай предложение.
3. **Дискурсивные шаблоны** → убирай шаблонные переходы, пиши связки от содержания.
4. **Тональные маркеры** → снижай пафос, убирай фальшивый энтузиазм.
5. **Структурные паттерны** → реорганизуй абзацы, если они построены по AI-шаблону.

### Шаг 3. Самопроверка

После переписывания пройдись по тексту ещё раз:

- [ ] Ни одного паттерна из таксономии не осталось.
- [ ] Текст не стал «рваным» — связность сохранена.
- [ ] Смысл оригинала не потерян и не искажён.
- [ ] Регистр (формальность/неформальность) соответствует контексту.
- [ ] Текст звучит так, как написал бы компетентный человек, а не LLM.

### Шаг 4. Внутренняя сверка (не выводить пользователю)

Мысленно пройдись по категориям таксономии и убедись, что ни один паттерн не пропущен. Это внутренний контрольный шаг — никакой лог в ответ не выводится.

---

## Взаимодействие с editor-policy

Если в рабочем процессе участвует `editor-policy` — сначала примени neuroslang-cleaner, потом editor-policy. Логика: сначала убери AI-штампы, потом приведи текст к редакторскому стандарту. Neuroslang-cleaner работает на уровне «язык AI → язык человека», editor-policy — на уровне «язык человека → хороший инфостиль».

## Принципы замены

1. **Конкретика вместо абстракции.** «Эффективный инструмент» → назови, что именно он делает.
2. **Глагол вместо номинализации.** «Осуществление контроля» → «контролировать».
3. **Прямое высказывание вместо хеджирования.** «Возможно, стоит рассмотреть вариант» → «Попробуйте...»
4. **Тишина вместо воды.** Если фраза не несёт нового смысла — удаляй, не заменяй.
5. **Разнообразие вместо шаблона.** Не заменяй один клишированный переход другим. Пиши связку, которая вытекает из содержания предыдущего абзаца.
6. **Сохраняй авторский голос.** Если в тексте есть живые места — не трогай их. Чисти только нейрослог. Исключение: метафоры убирай всегда (заменяй прямым высказыванием), если пользователь явно не попросил их сохранить.
